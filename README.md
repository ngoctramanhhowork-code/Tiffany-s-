# Data Analytics Portfolio

A collection of data analytics projects focused on business decision-making using Power BI, Power Query, DAX, SQL and Excel.

## Projects

### Commercial Lending Portfolio Analysis

Power BI analysis of 2,689 commercial lending facilities representing $302.23M in financed value.

Key themes:
- portfolio conversion and open pipeline
- borrower and geographic concentration
- product and vintage risk
- exposure exceptions
- data quality and lifecycle reconciliation
